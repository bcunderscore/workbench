# Dynamic Per-Post OG Share Cards — Design Spec

**Date:** 2026-07-26 · **Status:** Approved (Bryce: astro-og-canvas; card = BC_ mark + title + url)
**Ticket:** Workbench Dev — "Dynamic per-post OG share cards"

## What

At build time, generate a 1200×630 social-share card per **published post**: the cutting-mat background, the BC_ badge, the post's title (large), and `brycecampbell.com`. Shared post links get a bespoke branded card instead of the generic site card.

Build-time only (astro-og-canvas runs during `astro build`, like sharp) — **zero client JS**.

## Approach

- **`astro-og-canvas`** (installed; build-only dep, MIT). Uses a WASM renderer + embedded fonts, so it renders reliably on Vercel's Linux builders.
- Route endpoint `src/pages/og/[...route].png.ts` uses `OGImageRoute` over `publishedOnly(getCollection('posts'))`, keyed by `post.id`. Emits `/og/<id>.png` per post.
- Card composition (via `getImageOptions`): `bgImage` = the mat PNG (`cover`), `logo` = the BC_ badge, `title` = post title, `description` = `brycecampbell.com`, `border` = mint left edge (matches the site's card-accent motif), all-mono type (JetBrains Mono — leans into the terminal brand identity).

## Assets (already generated by controller — commit them)

- `src/assets/og/mat-bg.png` (1200×630, dark grid — no text)
- `src/assets/og/bc-logo.png` (mint BC_ badge, transparent surround)
- `src/assets/og/fonts/JetBrainsMono-Bold.ttf`, `JetBrainsMono-Regular.ttf`, `OFL.txt` (font license)

## Wiring

`src/pages/writing/[slug].astro`: the post's share image becomes **cover if present, else the generated card**: `image={ogCover ?? \`/og/${post.id}.png\`}`. This keeps photo-rich posts (e.g. a build log with a cover) sharing their photo, while text posts get a branded title card instead of the generic brand card. Projects unchanged (they already share their cover).

## Constraints

- `astro-og-canvas` is the only new dependency; it's build-time only. Fonts are OFL (license committed).
- `npm run check` 0/0/0; vitest 8/8; no content files committed; no Co-Authored-By trailer.
- **Validation must LOOK at a generated card** (not just confirm it 200s) — verify via a temporary published fixture post, view the rendered PNG, confirm mat bg + logo + title + url compose correctly, then delete the fixture.
